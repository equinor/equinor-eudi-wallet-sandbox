# Equinor &middot; EUDI Wallet Sandbox (Digdir) — Informational Site

A static informational website for **relying parties** about Equinor's work with the
**EU Digital Identity (EUDI) Wallet** using the national sandbox operated by the
Norwegian Digitalisation Agency (**Digdir**).

The site is a plain HTML/CSS/JS project with **no build step**, designed to be
deployed to **Azure Static Web Apps** directly from this GitHub repository.

> The sandbox is a testing/experimentation environment only — not a production
> identity service.

## Project structure

```
.
├── index.html                 # Main single-page site
├── 404.html                   # Custom not-found page
├── css/
│   └── styles.css             # Styles
├── js/
│   └── main.js                # Nav toggle + footer year
├── staticwebapp.config.json   # Azure SWA routing + security headers
└── .github/workflows/         # (Auto-generated by Azure when you connect the repo)
```

## Run locally

No tooling required. Open `index.html` in a browser, or serve the folder:

```powershell
# Option 1: Python
python -m http.server 5500

# Option 2: Node (if installed)
npx serve .
```

Then visit http://localhost:5500.

## Deploy to Azure Static Web Apps

This repository is the **source** you connect when creating the Static Web App.

1. In the [Azure Portal](https://portal.azure.com), create a **Static Web App**.
2. Choose **GitHub** as the deployment source and authorize access.
3. Select this repository and the **`main`** branch.
4. Build configuration:
   - **Build presets:** `Custom`
   - **App location:** `/`
   - **Api location:** *(leave empty)*
   - **Output location:** *(leave empty)*
5. Create. Azure adds a GitHub Actions workflow under `.github/workflows/` and
   deploys on every push to `main`.

Alternatively, via the Azure CLI + SWA CLI:

```powershell
az staticwebapp create `
  --name equinor-eudi-wallet-sandbox `
  --resource-group <your-resource-group> `
  --source https://github.com/<owner>/equinor-eudi-wallet-sandbox `
  --branch main `
  --app-location "/" `
  --login-with-github
```

## Editing content

All content lives in `index.html` (sections: Overview, Relying parties,
Equinor's role, Resources, Contact & FAQ). Update text there and push to `main`
to redeploy.
